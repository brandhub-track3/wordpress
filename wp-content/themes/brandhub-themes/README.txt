BRANDHUB THEME - INSTALLATION

1. Extract the ZIP file.
2. Copy the brandhub-theme folder to:
   wp-content/themes/
   (For Bedrock: web/app/themes/)
3. In WordPress Admin, open Appearance > Themes.
4. Activate "BrandHub Theme".
5. Open Appearance > Editor to edit the header, footer, templates and navigation.
6. Create a page named "Home" and choose it as the Homepage under Settings > Reading if needed.
7. Create a page named "Blog" and set it as the Posts page under Settings > Reading.

Included:
- style.css and theme.json
- functions.php
- Header and footer template parts
- Front page, home/blog listing, single post, archive and index templates
- Two reusable block patterns: Hero and Featured Posts

Notes:
- This is a starter block theme for WordPress 6.x.
- Add your own logo, menu links, hero background image and final brand copy.
- The navigation block uses the WordPress Navigation editor; configure links from Appearance > Editor.
